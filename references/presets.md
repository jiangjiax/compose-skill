# 组合配方：按维度拼出来的曲子

经典配方（styles.md 里的 18 个）各自是一段写死的程序：曲式、和声、伴奏、乐器绑在一起，改不了其中一样。
组合配方把一首曲子拆成几个**维度**，每个维度独立挑一个值，再配一套**编制**（谁演奏哪条线）。18 个预设就是 18 套挑好的组合，作曲卡可以只换其中一维，其余照预设。

> 组合出来的东西「合乎规则」，不等于「像某种真实存在的风格」。每个维度的选项都按某个时代的规则写好了，组合能扩大可能性，但新的规则还是要一条条写进去（见 add-style.md）。

## 维度

| 维度 | 卡里的字段 | 可选值（`node compose.mjs --list` 看最新） |

## 编制：功能 → 乐器

| 功能 | 做什么 | 什么时候进来 |
|---|---|---|
| melody 主旋律 | 唱动机长出来的旋律 | 一直在；写几件就会交接：对比段换下一件，高潮叠在一起 |
| counter 副旋律 | 在主旋律下面三度、六度反向走的慢线 | 能量 ≥0.55 |
| accomp 伴奏 | 按伴奏音型弹和弦 | 一直在；第二件 ≥0.5 |
| bass 低音 | 按低音音型 | ≥0.22，结尾一定在 |
| pad 铺底 | 长音和弦 | ≥0.45 |
| color 点缀 | 乐句开头轻点高音 | ≥0.5 |
| gliss 刮奏 | 段尾往上刮一串进下一段 | ≥0.45 |
| hits 定音鼓点 | 乐句开头敲根音，渐强段尾滚奏 | ≥0.6 |
| drums 鼓 | 按鼓型 | ≥0.3 |
| hetero 支声 | 和主旋律同一条线，并成长音（民乐） | ≥0.3 |
| tremolo 轮指 | 长音上快速重复（琵琶） | ≥0.45 |

写法：`"ensemble": {"melody": ["violin", "flute"], "accomp": [{"inst": "harp", "pattern": "arp-up", "octave": 1}], "bass": "cello"}`。`octave` 是手动指定整体升降几个八度（自动拉开音区时会跳过它）。声部名自动生成：一件就叫 `melody`，几件叫 `melody1`、`melody2`；`instruments`、`mute`、`volume`、edit.mjs 都用这个名字。

### 配器层会自动做的事（按 scripts/lib/orch.mjs 的乐器档案）

- **音区**：每件乐器整体挪到它最舒服的音区——主旋律靠近 72（中央 C 上方的 C），叠奏的第二件旋律乐器音域够高就放高八度，副旋律靠近 64，低音靠近 43；伴奏、铺底、副旋律和主旋律挤在一起（差不到 6 个半音）就往远离旋律的方向挪，同时必须在低音上面。
- **拉不住长音的乐器**（木琴、马林巴、八音盒、钢片琴、竖琴、吉他、羽管键琴）：派去铺底时改成琶音 / 稀疏点缀；唱旋律时长音改成滚奏或每拍补拨。
- **没有强弱的乐器**（羽管键琴、管风琴、八音盒、竖笛）：力度拉平，能量靠别的乐器加厚。
- **管乐、人声**：句尾留换气。
- **笨重的乐器**（大号、拉弓低音提琴、定音鼓）：快音合并；不派行走低音。
- **三声中部这类「轻段」**：能量压到 0.4 以下，铺底退出，只留最后一件旋律乐器唱。
- **同一段素材再出现但长度不同**：先原样沿用前面写过的旋律，不够再续写，耳朵认得出「回来了」。
- **同音连续三次以上**：中间那个改成上方邻音。
- 每一处改动都写进 `计算记录.md`「按乐器性格改的地方」。

## 主导动机与多版本

每首组合配方的旋律都从一个**动机**（6 个音阶级数的轮廓 + 一小节节奏）长出来：陈述 → 应答（重复或模进）→ 发展（截一半往上推）→ 终止；同一个字母的段落（A 和 A'）用同一段旋律，再出现时认得出。

轮廓和节奏用两条独立的随机数流，所以**同一个 `motifSeed` 在不同拍子、不同风格里是同一个轮廓**。作曲卡写 `versions` 时，后面的版本**连节奏也直接用第一个版本的**（3 拍的动机放进 4/4 就把最后一个音拉长），出几个共用主导动机的版本（宫廷版 + 流水线版、白天版 + 夜晚版），调和速度一致，剪辑里可以互切或叠在一起。电影配乐里的「主导动机」就是这个做法。想让主题藏在机械音型里，给那个版本的伴奏用 `motif-ostinato` / `motif-phase`。

## 画面切点

作曲卡写 `"cues": [{"at": 12, "label": "切到工厂"}, {"at": 30, "label": "高潮", "energy": 0.95}]`：段落边界对齐到切点（取整到小节），段名按曲式模板轮流套，`energy` 可以直接指定那一段多满。没写 `energy` 时按能量曲线算。
