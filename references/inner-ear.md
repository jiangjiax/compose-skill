# 内心听觉：不靠耳朵，怎么判断一首曲子有没有毛病

## 内心听觉是什么

受过训练的音乐家看着乐谱，脑子里就能「响」出来，这叫内心听觉（audiation）。贝多芬晚年几乎全聋还能作曲，靠的就是它：前三十年听过、弹过的无数音乐，在他脑子里沉淀成一个很准的模型，知道这几个音叠在一起会是什么效果、听的人会有什么感觉。

写曲子的 AI 没有耳朵，也没有这三十年。这里的替代办法是：**把「已知会让人听着别扭」的东西写成可以计算的检查**。它能抓出「错」，判断不了「好」，所以每份报告都要附上这句话，最后一关交给人的耳朵。

准确地说，这是一份**乐谱体检，只是内心听觉的下限**。真正的内心听觉是一个预测器：知道下一个音大概往哪走，也知道作曲家在哪一刻偏偏不往那走。这张表只有禁令，没有预测；「故意的意外」要靠作曲卡的 `dims.surprise` 主动写进去，不会从这张表里长出来。

**2026-11-06 的一次实证**（写科普文章《巴赫没有及格》时发现）：把真名曲交给旧版这张表，巴赫《平均律》C 大调前奏曲只拿 4 分（满分 22），强拍刺耳率 54% 不及格。原因是 35 小节里 19 小节是七和弦，旧规则把七和弦里那对隔 2 / 10 个半音的音一律判「打架」；旧的音域上限 24 个半音按「一个人能唱的旋律」定，一首典型的肖邦会挂科。于是做了三处修改：七和弦不算打架、阈值按时代从曲谱库量出来、加校准测试。修完后同四首曲子：BWV 772 22 分、BWV 846 14 分、K.545 18 分、肖邦 Op.9 No.2 18 分，都没有不及格项。

## 乐谱层（生成后立刻能算；用来判「过不过线」，不用来挑最高分）

| 检查 | 怎么算 | 阈值 | 为什么 |
|---|---|---|---|
| 强拍刺耳率 | 每个整拍上同时响的音：能排成三和弦或七和弦（大 / 小 / 减 / 增三和弦，属七、大七、小七、半减七、减七）就不算打架；排不成的，两两算音程，出现 1、2、6、10、11 个半音才算 | 有时代阈值时取「教材默认值」和「该时代真曲子第 75 百分位」里较宽的那个（巴洛克 23%、古典 23%、浪漫 25%）；没有时代时：严格 ≤15%、中等 ≤30%；印象派、爵士、布鲁斯只记录不判分 | 频率比复杂的音程放在强拍会刺耳；但七和弦是古典音乐的日常，不是错 |
| 外声部平行五 / 八度 | 最高和最低声部，相邻两拍都是纯五度或八度，并且同方向移动 | ≤2 通过，≤5 警告 | 两条线会融成一条、显得空；巴赫时代明令禁止，印象派、爵士故意用 |
| 音域 | 每个声部的音是否落在所选乐器真实能演奏的范围里 | 超出 >5% 判失败 | 真人演奏不了的谱子没有意义 |
| 乐器搭配 | 每两件同时响的乐器：发声方式（拉 / 吹 / 拨 / 敲 / 键盘 / 唱 / 电子）、亮度、实际音区中位数、是否在 instruments.md 的「好搭档」里 | 两件又亮又脆的敲 / 拨乐器音区差不到一个八度 = 失败；同类敲 / 拨 / 键盘乐器挤在同一音区且不是好搭档、或两件都很亮很脆 = 警告 | 编制三条：一个唱一个托、高中低分层、音色有反差。木琴 + 八音盒就是在这里翻的车 |
| 旋律 · 大跳比例 | 主旋律（组合配方按 melody 声部认；经典配方取最高声部）相邻两音跳超过 7 个半音（纯五度）的比例 | 时代阈值（第 90 百分位）：巴洛克 16.7%、古典 19.9%、浪漫 21.2%；没有时代时 ≤15% 且最大跳 ≤12 | 跳得多、跳得远就不好记；浪漫派本来就跳得更多 |
| 旋律 · 级进比例 | 相邻两音只差 1–2 个半音的比例（五声、布鲁斯音阶里小三度也算一级） | 时代阈值（第 10 百分位）：巴洛克 35%、古典 27%、浪漫 17%；没有时代时 ≥35% | 像走楼梯的走法 |
| 旋律 · 音域跨度 | 最高音减最低音 | 时代阈值：巴洛克 9–31、古典 9–46、浪漫 9–49 个半音；没有时代时 9–24 | 太窄单调；钢琴旋律本来就比人声宽，旧的 24 上限会冤枉肖邦 |
| （分解和弦织体） | 最高声部 60% 以上的进行在和弦音之间跳（3–9 个半音）、级进不到 25% | 命中时旋律三项只记录、不判分 | 巴赫 C 大调前奏曲这种没有「旋律」的曲子，按旋律判就是冤枉 |
| 重复与变化 | 旋律里每三个连续音程算一个「小片段」，看重复出现过的片段占多少 | 15%–80% | 没有重复，耳朵抓不到记忆点，像乱弹；重复太多就腻 |
| 节奏变化 | 旋律里有几种不同的时值 | ≥2 | 只有一种时值像机器打点 |
| 结尾回到主音 | 最后的和弦里有没有主音，旋律是否停在主和弦的音上 | 印象派、爵士不要求 | 不回家，听着像话没说完 |
| 张力起伏 | 每小节「音的密度 × 平均力度」组成一条曲线，算变异系数和最高点位置 | 变异系数 ≥0.15 | 从头到尾一个劲会累；很多好曲子的高潮在三分之二附近（只做提示，不判分） |

整首原样重复（`repeat`）的作品只查第一遍，表头会多一行「检查范围」——不然平行五度、重复率会被重复次数放大。

打分：通过 +2，警告 0，失败 −4。**挑曲规则（随机性旋钮）**：`tries` 首里，没有不及格项的算过线。默认 `randomness: low` 取过线里分最高的（满分曲最工整，也好听，只是好猜）；`mid` 按种子顺序取第一首过线的；`high` 打开「故意的意外」后取意外生效最多的。全都不过线才取分最高的。作曲卡写 `"ab": true` 就出两首都过线的给用户盲听。所有候选的分和过线情况写进 `计算记录.md`。

时代阈值从哪来：`node corpus_stats.mjs <MIDI 目录> <scores.json>` 用同一套算法量公有领域曲谱库（Mutopia；一首曲子一个目录，分谱合成总谱再量），写进 `references/corpus-thresholds.json`。2026-11-06 量了巴洛克 473 首、古典 127 首、浪漫 196 首、印象派 16 首。改了规则或阈值，跑 `node calibrate.mjs`：四首真名曲任何一项不及格就是规则在冤枉人。

## 音频层（渲染后再查）

| 检查 | 怎么算 | 阈值 |
|---|---|---|
| 峰值 | 整段最大电平 | ≤ −0.5 dBFS，否则可能爆音 |
| 低频 vs 中频 | 250 Hz 以下与 250–4000 Hz 的平均电平差 | < 8 dB，否则闷、糊 |
| 高频 vs 中频 | 4000 Hz 以上与中频的差 | < 0 dB，否则刺耳 |
| 中途断声 | 曲子中间超过 2 秒、之后又响起来的静音（结尾余音散掉不算） | 有就警告（可能是故意的休止） |

## 它做不到的

- 判断旋律「动人」、和声「有味道」：这些没有公认的公式。
- 发现「听起来很假」：采样和合成音色的真实感，只能靠人听。
- 风格是否地道：只能对照名作由人判断，或者交给独立评审读谱（见 critic.md），读谱同样不等于听到。
- 强拍刺耳率把七和弦里的七音也算作「打架」。严格风格（巴洛克、古典）的组合配方因此只在终止式用 V7，句中用三和弦；这是为了过检查做的保守选择，不是巴洛克规则本身。
- 阈值是经验值，不是定理。某项不过但用户听着喜欢，以用户为准，并把这个例外记进计算记录。
