# 乐器参考（53 种）

给不懂术语的人看的版本。提问时从这里摘「听起来像」当选项说明；配器时看「适合当」和「好搭档」。
「来源」= 本机用的是什么声音：**采样**（真乐器录音，最真）/ **GM**（macOS 自带 General MIDI 音色库，1990 年代 Roland 音色，够听但不够细腻）/ **合成**（公式算出来）/ **借用**（系统里没有，用相近乐器的声音代替）。

## 怎么搭一个编制（给用户的三条大白话）

1. **一个唱、一个托**：一件乐器唱旋律（主奏），一件乐器弹和弦或分解和弦（伴奏）。最简单也最不容易乱。
2. **高、中、低各有人**：旋律在高处，和声在中间，低音在下面，三层不要挤在同一个音区。
3. **音色要有反差**：吹的配弹的（长笛 + 竖琴）、拉的配敲的（小提琴 + 钢琴）比两件同类乐器更清楚。

**这三条现在由程序检查**（`scripts/lib/orch.mjs`）：生成前就预检，自检表里有「乐器搭配」一项。
- 不合适（✗）：两件又亮又脆、一敲就散的乐器（木琴、八音盒、钟琴、钢片琴、班卓琴……）音区离得不到一个八度——会糊成一片、扎耳朵。
- 有风险（△）：两件发声方式一样的敲 / 拨 / 键盘乐器挤在同一音区，又不在彼此的「好搭档」里；或者两件都很亮很脆。拉的、吹的、唱的同类乐器（弦乐组、木管组）不算，本来就常合奏。
- **提问时出乐器选项前，先对照「好搭档」和这三条筛一遍**；不合规的组合不放进选项。用户坚持要，就先说清风险再生成。
- 「好搭档」列是程序读取的真源：改这一列，检查跟着变。名字要和「名字」列一致（或写「弦乐」「木管」「乐队」「几乎所有」）。

## VSCO 2（管弦乐器的首选音源）

2026-11-06 作者盲听《忐忑到勇气》：同一份谱子，VSCO 版「明显好得多」，比只校过音的爱荷华版好。所以能用 VSCO 的乐器一律优先 VSCO，爱荷华只做备用。

VSCO 2 Community Edition（Versilian Studios，https://github.com/sgossner/VSCO-2-CE，CC0）。整库 2.3 GB，只下这几个文件夹（约 550 MB），放进 `~/.cache/compose-skill/src/vsco2/`，保持仓库里的原路径：

- 弦乐：`Strings/Violin Section/susVib`、`Strings/Viola Section/susvib`、`Strings/Cello Section/susvib`（这三个拼成「弦乐合奏」）、`Strings/Solo Violin/Arco Vib`、`Strings/Solo Contrabass/SusVib`
- 铜管：`Brass/F Horn/sus`、`Brass/Trumpet/susvib`、`Brass/Tenor Trombone/sus`、`Brass/Tuba/sus`
- 木管：`Woodwinds/Flute/susvib`、`Woodwinds/Oboe/Vib`、`Woodwinds/Clarinet/susLong`、`Woodwinds/Bassoon/vib`、`Woodwinds/Piccolo/Sus`
- 定音鼓：`Percussion/Timpani/`（五面鼓，实测音高写死在 samples.mjs 的 TIMPANI 表里，各自重采样到最近的半音）

一共约 750 MB。
GitHub 直连本机只有约 20 KB/s，走 7892 代理约 400 KB/s：先用 `api.github.com/repos/sgossner/VSCO-2-CE/git/trees/master?recursive=1` 拿文件清单，再用 `curl -x http://127.0.0.1:7892` 按 `raw.githubusercontent.com/sgossner/VSCO-2-CE/master/<路径>` 并行下载。
已知问题：文件名里的八度写法各文件夹不统一（程序按实测投票纠正）；每个采样加载时校音到约 ±10 音分；采样间距超过 5 个半音的空档（圆号 C4–D5）用校过音的爱荷华单音补。萨克斯 VSCO 没有，继续用爱荷华。
