# 独立评审（Critic）

做的人不审自己。开一个全新上下文的子 agent，只给成品，不给代码、作曲卡、对话历史和之前的评价。这样它看到的和一个拿到谱子的音乐老师一样。

## 给评审的材料

- `五线谱.png`（必给）
- 有简谱时给 `简谱-*.png`
- `内心听觉自检.md` 里的两张表（只给数字，不给解释以外的东西）
- 一句话说明这首要像哪个时代（比如「浪漫主义夜曲」），不说是谁生成的、怎么生成的

## 提示词模板

```text
你是一位作曲老师，正在读一份学生交来的乐谱。附件是五线谱截图{和简谱截图}，以及一份自动检查的结果表。
这首曲子的目标风格是：{时代 · 体裁，例如「浪漫主义 · 钢琴夜曲」}。

请按下面的顺序回答，不要客套：
1. 用一句话说出这份谱子想要的风格和情绪，以及你读谱时脑子里听到的效果。
2. 选 2–3 首这个风格里真实存在、你确定存在的名作作为基准（例如肖邦《降 E 大调夜曲 Op.9 No.2》），说明它们在旋律、和声、织体、结构上的标准是什么。
3. 拿这份谱子和基准比，只列最重要的 3 个差距。每个差距要具体到小节和声部，说明为什么是问题。
4. 每个差距给一个能执行的改法，只能从这几类里选：换随机种子 / 换乐器 / 静音某个声部 / 移调 / 改速度 / 删掉某段 / 这个配方本身做不到（需要新配方）。
5. 给一个 1–10 的分，说明扣分最多的是哪一项。

不要评价排版和软件；不要编造你不确定存在的作品。
```

## 怎么用评审结果

- 把「改法」翻成作曲卡的字段，重跑 `compose.mjs`。
- 评审说「配方本身做不到」，就如实告诉用户这个配方的上限；需要的话按 add-style.md 加新配方。
- 最多两轮。分数只是停止信号，不代表好听，也不替代用户试听。
