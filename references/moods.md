# 情绪与场合 → 推荐（提问时用来出选项）

用户说不清风格时，从情绪或场合倒推。每一行的推荐都要在 presets.md / styles.md / instruments.md 里有对应条目；推荐是起点，最后以用户试听为准。

**先看组合预设**：华丽宫廷 → court-minuet、baroque-concerto；热血 / 宏大 → romantic-symphonic、epic-film；坚持积累 → minimal-build、bolero-build；学习背景 → lofi；温柔抒情 → romantic-nocturne、pop-ballad；古风 → jiangnan；庆典行进 → march；暧昧拉扯 → tango；慵懒都市 → jazz-swing、blues；梦幻 → impressionist。下表的「推荐配方」是经典配方 id，组合预设对应关系见 presets.md 最后一列。

## 情绪

| 温柔、思念、夜晚 | nocturne、lied | 慢 | 大调 / 小调转大调 | 钢琴、大提琴、二胡、竹笛 |
| 甜蜜、浪漫、幸福 | waltz、rondo | 中快 | 大调 | 小提琴、钢琴、竖琴 |
| 活泼、俏皮、可爱 | rondo、dice、variations | 快 | 大调 | 长笛、单簧管、弦乐拨弦、钢片琴 |

## 场合

| 场合 | 推荐配方 | 时长建议 | 注意 |
|---|---|---|---|
| 视频背景（人在说话） | satie、minimal、period | 1–2 分钟可循环 | 旋律别太抢；少用人声、小号；音量留给配音 |
| 片头 / 片尾 | rondo、motif（结尾）、chorale | 15–30 秒 | 开头要有辨识度，结尾要落回主音 |
| 科普讲解配乐 | variations、period、dice | 1–2 分钟 | 结构清楚的古典风最不干扰理解 |
| 学习 / 工作背景 | minimal、satie、canon | 越长越好 | 避免突然的强弱变化 |
| 助眠 / 冥想 | debussy、satie、nocturne | 3 分钟以上 | 慢、弱、没有打击乐 |
| 游戏关卡 | sequence、minimal、bolero | 循环段 | 能无缝循环（结尾回到开头的和弦） |
| 婚礼 / 庆典 | waltz、canon、chorale | 2–3 分钟 | 大调，明亮 |
| 中国风内容 | sizhu | 1 分钟左右 | 告诉用户民乐音色是借用的 |
| 给乐器练习（出谱为主） | period、variations、sizhu | 16–32 小节 | 选好吹好拉的音域，出简谱 |
| 音乐科普 / 讲某个时代 | 对应时代的配方 | 30 秒–1 分钟 | 说明是「仿作」不是原曲 |
